Predicting agricultural commodity prices is a challenging task due to high volatility driven by seasonal cycles, weather fluctuations, transportation costs, and changing supply-demand dynamics. Accurate forecasts help farmers, traders, and policymakers make informed decisions, enabling price stability and improved market planning.

Project Overview
This project delivers a comprehensive machine learning framework for forecasting agricultural commodity prices specifically in Telangana's market yards. Leveraging a rich dataset of over 200,000 daily transaction records sourced from government open data, the system captures critical market insights across major crops and multiple markets.

Key Features
Extensive Data Handling: Includes rigorous data cleaning and feature engineering to ensure high-quality inputs.
Robust Machine Learning Models: Implements and compares multiple algorithms including Linear Regression, Decision Tree Regressor, Random Forest, XGBoost, and CatBoost.
Top Performance: XGBoost model achieved the best accuracy with an R² score of 0.93 and mean absolute error (MAE) around ₹200, closely followed by CatBoost with an R² of 0.91.
Complex Relationship Modeling: Successfully models nonlinear interactions among variables such as market yard, commodity type, arrival quantity, and transaction date.
Interactive Web Application: A user-friendly Streamlit interface allows users to select a market yard, commodity, and date to receive real-time price predictions.
Benefits
Empowers farmers and traders with actionable price forecasts to optimize their selling and buying decisions.
Enhances transparency and efficiency in Telangana's agricultural markets.
Supports policymakers by providing data-driven insights to stabilize commodity prices.
This project represents a significant step toward leveraging advanced data science to support Telangana’s agricultural economy.
